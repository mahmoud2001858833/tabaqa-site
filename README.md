# طبقة: رفع الموقع

في هذه النسخة يبقى مفتاح Groq على الخادم فقط، ولا يظهر داخل الصفحة.

## رابط عام عبر Vercel (مجاني)
1. أنشئ مستودعًا فارغًا على GitHub وارفع إليه هذا المجلد. ملف `.env` مستثنى من الرفع.
2. من vercel.com اختر Add New ثم Project واستورد المستودع.
3. في Environment Variables أضف الاسم `GROQ_API_KEY` وقيمته مفتاحك.
4. اضغط Deploy. ستحصل على رابط عام مثل `https://tabaqa.vercel.app`.
5. افتح الرابط، ثم الإعدادات، ثم «فحص الاتصال».

## التشغيل على جهازك
1. ثبّت Node.js بالإصدار 18 أو أحدث.
2. تأكد أن ملف `.env` فيه: `GROQ_API_KEY=مفتاحك`
3. من هذا المجلد شغّل: `node server.js`
4. افتح: http://localhost:3000

## ملاحظات
- يحدد الوسيط 40 طلبًا في الدقيقة لكل زائر. غيّر الرقم عبر `RATE_LIMIT_PER_MIN`.
- كل زائر يستهلك من حصة مفتاحك، فأضف تسجيل دخول إذا كثر الزوار.
